# VibePolar Public Site

VibePolar iPhoneアプリの公開情報サイトです。

- `/`: アプリ概要
- `/privacy`: プライバシーポリシー
- `/support`: サポートとアカウント削除手順

本番URL:

- `https://vibepolar.app/`
- `https://vibepolar.app/privacy/`
- `https://vibepolar.app/support/`

GitHub Pagesでは `docs/CNAME` により `vibepolar.app` を使用します。

## Commands

```bash
npm install
npm run dev
npm test
```
